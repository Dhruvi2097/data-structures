# Data Structures

This repository contains the practical programs performed as part of my Data Structures subject.

## Practicals

- Practical 01 Array operations(insertion, deletion, traversal, and search).
- Practical 02 print array in reverse order using dynamic memeory allocation & program to demonstrate call by value and call by reference.
- Practical 03 Program to implement stack using array (operations: push, pop, peek and display).
- Practical 04 program to convert an expression from infix to postfix & program to evaluate a postfix expression.
- Practical 05 program to simple queue and circular queue using array (operations: enqueue, dequeue and display).

More practicals will be added as the course progresses.

## Language

- C
